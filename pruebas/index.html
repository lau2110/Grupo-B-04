Descripción del proyecto

Este proyecto presenta una propuesta de Arquitectura Orientada a Servicios (SOA) para la gestión de cotizaciones entre los canales web y telefónico, utilizando el patrón Logic Centralization y una API REST para mejorar la coherencia tarifaria y la trazabilidad de las operaciones.

Es un diseño académico: no describe una API verificada de Oasis o Paraty Tech, no accede a código interno y no mide resultados de producción. Los identificadores, importes y políticas son sintéticos e ilustrativos.

Servicio REST

  • POST /v1/cotizaciones — genera una oferta y la persiste
  • GET /v1/cotizaciones/{id} — recupera una cotización sin recalcular
  • PUT /v1/cotizaciones/{id}/decision — registra la decisión del cliente

Documentación de la API

La documentación de la API fue desarrollada utilizando OpenAPI/Swagger.

  • openapi.yaml — contrato de la API
  • swagger.json — especificación generada para Swagger UI

Con el servidor en ejecución, la interfaz interactiva queda disponible en http://localhost:8080/swagger-ui.html.

Evidencias de funcionamiento

Prueba 1 — Crear cotización

Estado esperado: 201 Created

POST /v1/cotizaciones
Authorization: Bearer <token-demo>
Idempotency-Key: demo-001
Content-Type: application/json

{
  "hotelId": "OASIS-DEMO",
  "habitacionId": "DOBLE",
  "planTarifaId": "FLEX",
  "entrada": "2026-11-20",
  "salida": "2026-11-22",
  "adultos": 2,
  "edadesMenores": [],
  "moneda": "MXN"
}

Prueba 2 — Consultar cotización

Estado esperado: 200 OK

GET /v1/cotizaciones/cot-demo-001
Authorization: Bearer <token-demo>

Prueba 3 — Cotización vencida

Estado esperado: 409 Conflict

PUT /v1/cotizaciones/cot-demo-001/decision
Authorization: Bearer <token-demo>
If-Match: "d1"
Content-Type: application/json

{ "estado": "ACEPTADA" }

Prueba 4 — Acceso no autorizado

Estado esperado: 401 Unauthorized

GET /v1/cotizaciones/cot-demo-001
(sin cabecera Authorization)

Casos de aceptación

CasoResultado esperadoVerificaciónEstado
Entradas equivalentes web / teléfono Mismos importes y versiones Prueba automatizada CotizacionEquivalenciaTest ✅
Beneficio no elegible Sin descuento aplicado Prueba automatizada FidelizacionTest ✅
Reintento POST con misma clave Un único identificador y registro Prueba automatizada IdempotenciaTest ✅
Cotización vencida 409 sin sobrescribir el precio Evidencia 3 y VigenciaTest ✅
Consulta de cotización ajena 404 sin datos de la oferta Prueba automatizada AutorizacionTest ✅
Dependencia o registro caído 503 sin cotización incompleta Prueba con dependencia simulada ✅

Los casos marcados corresponden a pruebas ejecutadas sobre el servicio local con datos sintéticos. No son pruebas de integración contra los sistemas de Oasis.
